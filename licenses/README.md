# Dependency license texts

These files retain the controlling upstream license texts and notices for bundled
JediTerm, pty4j and their shared runtime dependencies. Apache-2.0 is selected for
our JediTerm fork; the upstream dual-license texts and original notice are retained.
Release packaging also extracts legal metadata from every resolved runtime JAR,
including FlatLaf, Kotlin, annotations and Jackson JSR-310, into the installed
`THIRD-PARTY-LICENSES` tree.
